# women-safety-app
This is a comprehensive Women's Safety Web Application designed to provide immediate assistance, secure navigation, and peace of mind during emergency situations through a clean, modern, and user-friendly interface.

Key Features

User Authentication: Secure registration and login system with persistent session handling.

SOS Panic Button: Instant alert trigger for emergency situations.

Safe Route Navigation: Dedicated mapping feature for secure travel paths.

Realistic Fake Call Simulation: Incoming call screen layout ("Mom") with Answer/Decline actions to escape uncomfortable situations.

Live Location Sharing: Real-time location sharing toggle with emergency contacts.

Emergency Contacts Management: Add, view, and delete trusted emergency contacts.

Personalized Dashboard: Displays the logged-in user's profile details and quick-access feature cards.

Technologies Used

Frontend: React.js, React Router (react-router-dom), and React Hooks (useState, useEffect).

Backend & Storage: MongoDB for data storage.

Authentication & Alerts: Firebase Authentication and Firebase Cloud for sending SOS alerts.

Mapping & Navigation: Google Maps API integrated with SafetyMaps key for safe route mapping.

Styling: Responsive inline CSS utilizing CSS Flexbox and CSS Grid.
